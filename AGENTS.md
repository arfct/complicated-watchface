# Complicated

A Wear OS watch face that is one complication filling the screen, with a
clock over it: digital or analog, at the top, center or bottom. Small at the
top or bottom, where the complication's content moves into the rest of the
screen; large at the center, where the content splits above and below it.

Watch Face Format 5 (`minSdk 37`, Wear OS 7), code-free. The whole face is
`wff/src/main/res/raw/watchface.xml`, generated by
`wff/tools/generate_watchface.py`. **Edit the generator and re-run it; never
hand-edit the XML.** The format version in `wff/src/main/AndroidManifest.xml`
and `minSdk` in `wff/build.gradle.kts` must move together: Play filters by
`minSdk`, so a mismatch offers the face to watches that cannot render it.
Format 5 is used for auto-sized text (`isAutoSize` with `minSize`), so
complication text shrinks to fit instead of clipping.

| Task | Command |
|------|---------|
| Regenerate XML | `python3 wff/tools/generate_watchface.py` |
| Build | `./gradlew :wff:assembleDebug` |
| Install | `adb install -r wff/build/outputs/apk/debug/wff-debug.apk` |
| Activate | `adb shell am broadcast -a com.google.android.wearable.app.DEBUG_SURFACE --es operation set-watchface --es watchFaceId com.artifact.complicated.wff` |
| Validate | `java -jar wff-validator.jar 5 wff/src/main/res/raw/watchface.xml` |

The validator comes from https://github.com/google/watchface
(`third_party/wff`, `./gradlew :specification:validator:executable-jar`).
The Gradle build does not check WFF schemas. Without a system JDK, Android
Studio's works: `JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"`.

An emulator must be Wear OS 7 (API 37) or newer to load format 5.

## Complication types

`supportedTypes` is a preference order: when a provider is picked, the
system gives the slot the first listed type that provider offers. Photo
first, so a photo provider fills the screen; gauges before text, so a
battery arrives as a ring. `WEIGHTED_ELEMENTS` is left out: its segments
arrive as one space-separated list that expressions cannot split.

| Type | Rendering |
|---|---|
| `PHOTO_IMAGE` | Full screen, with a scrim under the clock |
| `RANGED_VALUE`, `GOAL_PROGRESS` | Ring at the bezel; icon, text and title in the free area |
| `SHORT_TEXT` | Icon, text and title in the free area |
| `LONG_TEXT` | Icon, two lines of text, title |
| `SMALL_IMAGE` | Full screen when `IMAGE_STYLE` is photo, else a large icon |
| `MONOCHROMATIC_IMAGE` | Large icon |

Ambient drops the complication and keeps the clock, since a full-screen
photo would light far more than Play's 15% illuminated-pixel guidance.

## Driving the editor with adb

- `KEYCODE_HOME` opens the app launcher, not the watch face. A long-press
  there opens an app's options. Reach the face with `KEYCODE_BACK` and
  check `uiautomator dump` shows `content-desc="Watch face…"` first.
- The face picker labels every face "Activate …", including the current
  one. A stray horizontal swipe in the picker switches faces. Confirm the
  editor is this face's by its page count ("n of 3 in list").
- The editor reopens on the last page used.
- Options change with the crown: `adb shell input rotaryencoder scroll
  --axis SCROLL,-1` steps forward, `SCROLL,1` back; lists do not wrap.
